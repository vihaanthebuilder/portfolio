# Vihaan's World 🧱♟️🚀

A colorful, kid-friendly portfolio website for Vihaan — a 7-year-old **builder, chess player, and creator**.

**Live site:** https://vihaanthebuilder.github.io/portfolio/

## Sections
- **LEGO Lab** — featured builds (Space Shuttle, Castle, Robot, Race Car)
- **Chess Journey** — rating progress chart, tournament results, puzzle milestones
- **Achievement Wall** — badges and milestones
- **Project Gallery** — LEGO, chess, school & science projects
- **2026 Goals** — what Vihaan is working toward next

## Tech
- Single self-contained `index.html` (HTML + CSS + JS, no build step)
- Rating chart drawn with inline SVG (no libraries)
- Mobile friendly, rounded cards, LEGO + chess theme
- Deployed via **GitHub Actions → GitHub Pages** (`.github/workflows/pages.yml`)

## Editing
Open `index.html` and edit the content directly. To add real photos, replace the
emoji placeholders (the `.ph` and `.gtile` blocks) with `<img>` tags.

> Contact is **parent-managed** — no public personal info is published.
